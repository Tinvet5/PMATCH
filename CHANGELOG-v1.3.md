# PLUGIN MATCH — Changelog v1.3

## Objetivo
Convertir la experiencia pública de PLUGIN MATCH en una interfaz realmente responsive y funcional, manteniendo el diseño oscuro/editorial y el pipeline Excel + Studio existente.

## Cambios

### Global
- Nuevo menú responsive para tablet y móvil.
- Header reorganizado para evitar solapamientos.
- Búsqueda pública disponible desde Home, Catálogo y módulos.
- Placeholder de cuenta preparado para la futura etapa de autenticación.

### Home
- Hero adaptado a orientación vertical.
- Carrusel con paginación visual.
- Soporte de swipe táctil.
- Familias adaptativas a 4/2/1 columnas.
- Tarjetas de familia visualmente más consistentes.

### Catálogo
- Drawer móvil para filtros.
- Contador de filtros activos.
- Chips removibles para filtros aplicados.
- Tarjetas horizontales compactas en móvil.
- Mejoras de espaciado, tipografía y toolbar.

### Módulos
- Nuevo modo móvil para diagramas:
  - hotspots visibles,
  - callouts y líneas ocultos en pantallas pequeñas,
  - selector horizontal de controles,
  - explicación persistente debajo de la imagen.
- Primer control seleccionado automáticamente en móvil cuando existe.
- Cards inferiores reorganizadas para lectura vertical.

### Studio
- Sin cambios destructivos.
- Se conserva el drag fix de v1.1, Excel v1.2 y catálogo público v1.2.1.
- Indicador de versión actualizado a v1.3.

## Compatibilidad
- Desktop: experiencia Canva/desktop preservada.
- Tablet: navegación compacta + menú lateral.
- Mobile: layouts específicos en vez de simple escalado del escritorio.
